Fishing Game

This game was inspired by a game on itch.io called What Lives Below. I really liked the concept, but I wanted to change a few things, so I'm making my own game.
I've decided to make my version multiplayer because this game seems perfect for that. Killing massive sea creatures with friends sounds like fun. I decided to make my game set around the 1940's or 50's.
