About This Website

Created: 2/21/2026 | Updated: 2/22/2026

who this is for

This website is mostly for myslef to document where I've been and what I've done. It's also been a fun project I can chip away at over time. It'll never be done, but if I add a little each time it'll eventually become something. And when it comes up, it's something I can show people and be proud of.
I saw this video about photography and creation, and I thought it was pretty interesting. It encapsulated a lot of my feelings regarding making things.

I want to make stuff; but why do I want to make it? Who is it for? It's likely both for myself and for those around me. I'm not interested in a large audience, but a close community of those I can show it to is nice.

Methodology (is this the right word)

I've tried to keep this website simple and lightweight. I want it to be stylish and clean, but also fun and information heavy. For much of the website (especially the blogs), I've taken inspiration from Gorkem's webspace. It feels like the "glory days" of the web and I'd like to replicate that. I've intentionally left off bloat like related articles in order to keep this a simple, usable website.
I need to avoid falling into the pit of automation. Since all the articles follow the same template, it would be easy to create a system that removes all the repetition. But is it worth the time? I'm already doubting myself, but I've gotta say no. It would just be another system to deal with and I would lose the ability to add slight differences, like a background image or an easter egg. I should stick with what I've got.
